~/About

I’m a Product Security Engineer at PhonePe with 5+ years of experience spanning offensive security consulting and in-house product security. I test web applications and APIs, perform mobile pentesting, and review source code to find vulnerabilities before products reach production.

My work goes beyond an assessment: I review application changes, triage security tickets, and build tooling that makes security monitoring more useful. Previously, at Payatu, I delivered client penetration tests, developed security procedures, and designed CTF challenges for internal and external competitions.

I’m also a credited researcher for CVE-2023-5971. My earlier experience in phishing investigations and software automation gives me a broader view of how systems are built, attacked, and defended. I’m now learning about AI security while exploring LLM-assisted security review workflows.
